11주차 실습 과제 기록표 ② - 코드 커버리지
==========================================

실행 명령:
python -m pytest --cov=load_scores --cov-report=term-missing .\week11\test_load_scores.py

측정 도구: pytest-cov 7.1.0, coverage 7.17.2
테스트 실행 결과: 8개 수집, 6 passed, 1 failed, 1 xfailed

커버리지 측정 결과 (week11/load_scores.py)
-------------------------------------------
- 전체 실행 대상 문장 수: 45
- 실행된 문장 수: 27
- 실행되지 않은 문장 수: 18
- 커버리지: 60%
- 실행되지 않은 줄: 48-49, 55-56, 58-59, 63-65, 77-86

테스트가 지나가지 않은 코드와 이유
----------------------------------
- 48-49행: CSV 데이터 행의 열 개수가 2가 아닐 때 기록하는 분기입니다.
  실행 테스트에는 열이 잘못된 행이 없습니다.
- 55-56행: 이름이 빈 문자열일 때 건너뛴 항목을 기록하는 분기입니다.
  실행 테스트에는 이름이 빈 데이터 행이 없습니다.
- 58-59행: 점수가 빈 문자열일 때 기록하는 분기입니다.
  실행 테스트에는 점수가 빈 데이터 행이 없습니다.
- 63-65행: 점수를 정수로 변환할 때 ValueError가 발생한 경우 기록하는 분기입니다.
  실행 테스트에는 숫자가 아닌 점수 행이 없습니다.
- 77-86행: 모듈을 직접 실행했을 때 명령행 인수를 읽고 결과를 출력하는 부분입니다.
  pytest는 load_scores를 모듈로 가져와 호출했으므로 이 직접 실행 블록은 실행되지 않았습니다.

참고
----
- 점수 0, 100, 101 경계 테스트와 정상 파일, 쉼표가 포함된 이름, 파일 없음, 빈 줄 테스트가 실행됐습니다.
- 빈 줄 테스트는 점수 목록 검증까지 통과했으나 skipped 길이 검증에서 실패했습니다.
- 헤더만 있는 파일 테스트는 pytest.xfail로 종료되어 이 테스트 안에서는 load_scores를 호출하지 않았습니다.
- 첫 커버리지 시도는 대상 모듈 이름이 실제 import 이름과 맞지 않아 데이터를 수집하지 못했습니다.
  위 결과는 --cov=load_scores로 다시 실행해 보고서와 저장된 소스 줄 번호를 대조한 실제 측정치입니다.
- 소스 파일과 테스트 파일은 수정하지 않았습니다.
